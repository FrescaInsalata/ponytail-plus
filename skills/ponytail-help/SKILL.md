Show this card, in the user's language, then stop.

```
ponytail-plus · think expensive, write cheap

LEVELS   /ponytail lite    build it, name the lazier option
         /ponytail         full: the ladder enforced (default)
         /ponytail ultra   YAGNI extremist, challenges the requirement
         /ponytail off     or "stop ponytail" / "normal mode"

LADDER   exist? → reuse → stdlib → native → installed dep → one line → minimum

PHASES   understand  plan/design/research/plan mode → think freely
         implement   default → ladder at max, surgical diff
         review      bugs + delete-list

SKILLS   /ponytail-review   delete-list for a diff or plan (net: -N lines)
         /ponytail-audit    whole-repo bloat audit, ranked
         /ponytail-debt     ledger of `ponytail:` shortcut comments
         /ponytail-help     this card

DEFAULT  env PONYTAIL_DEFAULT_MODE=lite|full|ultra|off
NEVER    cut validation, data-loss handling, security, accessibility
```
